# _rodolfo — Estudos de Concurso

Material de estudo para concursos na área de **trânsito e segurança pública**.

## Concursos

- **ARAGUAINA/** — Concurso Público da **ASTT — Agência Municipal de Segurança, Transporte e Trânsito de Araguaína/TO** (Edital 002/2026, banca IDIB).
- **gurupi/** — pasta reservada, ainda vazia.

## Como usar (ordem de leitura)

A numeração das pastas define a ordem de estudo:

1. **00_EDITAL** — comece aqui: edital, conteúdo programático (Anexo III) e tabela das provas. É o mapa de tudo.
2. **01_PORTUGUES** — disciplina com maior peso na prova (ver `03_Tabela_das_Provas.docx`).
3. **02_LEGISLACAO** — núcleo de conhecimentos específicos: Constituição Federal, CTB (Lei 9.503), Resoluções CONTRAN (em ordem numérica), Lei 11.343 (antidrogas).
4. **03_HISTORIA_GEOGRAFIA_ARAGUAINA** — história e geografia do município de Araguaína.
5. **04_PROVAS_ANTERIORES** — prova de Agente de Trânsito e Transporte (concurso de Petrolina/PE) para treino.
6. **05_CADERNO_DE_ESTUDO** — caderno de resoluções CONTRAN (IDIB), para consulta e anotações.
