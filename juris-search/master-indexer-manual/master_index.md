- **API de busca**: `POST /v1/qdrant/search`
- **Filtros disponíveis**: `tribunal`, `relator`, `outcome`, `data_julgamento`, `classe`
- **Metadata por documento**: ementa, partes, advogados, assuntos, legislação citada, court_specific

### Exemplo de busca

```bash
curl -X POST http://localhost:8066/v1/qdrant/search \
  -H "Content-Type: application/json" \
  -d '{"collection_name":"juris_br_v1","query_text":"tráfico de drogas","limit":5,
       "filter":{"must":[{"key":"tribunal","match":{"value":"TJSP"}}]}}'
```

## Pipeline de Extração

1. **Fontes**: PDFs (TJSP/TJMS/TJCE) + DOCXs (TJRS) em `court_samples/jurisprudence-documents/`
2. **Extração**: `court_extractor.py` — regex mecânico por tribunal
3. **Saída**: `extracted_documents/` — JSON estruturado por documento
4. **Ingestão**: `ingest_to_qdrant.py` — batch via API `structured_ingest`
5. **Coleção**: `juris_br_v1` — 706 vetores, 768-dim, metadata completa
